## Getting Started with Integrated Backend

This version includes a fully integrated Node.js/Express backend with MySQL database support.

### Quick Start

1. Clone Repository
```bash
git clone https://github.com/themewagon/adminhmd.git
cd adminhmd-1.0.0
```

2. Install Dependencies
```bash
npm install
```

3. Start the Application
```bash
npm start
```

The application will run on `http://localhost:3000`

### Available Scripts

```bash
npm start          # Start the server
npm run dev        # Start with hot reload (requires nodemon)
npm run db:init    # Initialize database
npm run db:seed    # Seed sample data
npm test           # Run tests
npm run test:watch # Run tests in watch mode
```

## Architecture

- **Backend**: Node.js + Express.js
- **Frontend**: Bootstrap 5 + Vanilla JavaScript
- **Database**: MySQL
- **API**: RESTful API with JWT authentication
